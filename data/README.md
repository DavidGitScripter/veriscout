# Datenbereiche

- `public/`: leere Vorlagen und klar gekennzeichnete synthetische
  Demonstrationsdaten; Zielorganisationen werden pro Auftrag uebergeben.
- `development/`: synthetische oder kuratierte Entwicklungsdaten; niemals Teil
  eines konfirmatorischen Holdouts und nie nur einem Versuchsarm zugänglich.

Laufzeit-, CRM- und personenbezogene Daten gehören nicht in diesen Ordner.
